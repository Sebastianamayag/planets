# Prueba Tecnica  

## Desarrollo
Esta app muestra planetas del sistema solar, se desarrollo bajo el framework de expo
puesto que es el recomendado para desarrollo con react native.

Para el tema de manejo de estados se opto por usar react query ya que permite
hacer catch de datos y asi mejora el rendimiento de la app.
El tema de la navegación se uso el expo-router el cual permite un
una dinamizacion en las rutas lo cual hace que sea facil
tanto el configurarlas como el crear una nueva.
Por ultimo para la persistencia de los datos se uso async storage puesto que no habia 
compatibilídad con la libreria de react native mmkv.

**Hecha con React Native + Expo + React Query**
